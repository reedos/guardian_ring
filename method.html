Show the reasoning

The model will separate published inputs from calculations and illustrative choices.

Current scope

The scaffold stores scenario choices and tests the viewer contract. It does not yet calculate or display orbital, optical, thermal or detection performance.

Physical calculations will be implemented only after the source review and look prototype. Civil instrument values will stay attached to the named instrument.

Calculations

No physical calculations are enabled.

Assumptions

Placeholder geometry has no physical scale and represents no satellite, telescope or detector. Scenario selections are interface placeholders.

How this is checked

Type checks, unit tests and a strict claim audit run alongside browser gates for the parts, framing, controls, camera paths, rendering quality, performance and links.
