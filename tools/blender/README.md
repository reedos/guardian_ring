# Hardware asset pipeline

Phase 0 includes only a neutral test cube with no physical scale. It is not a hardware asset.

After look approval, generate every detailed hardware model using `build-*.py` here and save GLBs under `public/models/`. Every rebuilt GLB must receive a new `?v=N` key at its load site. Geometry is representative/as drawn unless an opened public source dimensions it. No manufacturer logos or invented part numbers or masses.
